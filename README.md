# mitotl-ia
Plataforma de inteligencia artificial para análisis, comparación y retroalimentación de movimientos de danza.

Las referencias del catálogo se obtienen mediante URLs del AIST Dance Video Database y se descargan temporalmente durante la sesión. El uso de AIST Dance DB requiere respetar sus [términos de uso](https://aistdancedb.ongaaccel.jp/terms_of_use/), incluyendo la atribución correspondiente y la prohibición de redistribuir el contenido sin autorización. Para esta plataforma se utiliza la referencia: [AIST Dance Video Database](https://aistdancedb.ongaaccel.jp/).
