# Convenciones


| Nivel             | Definición                                                             | Acción                                            |
| ----------------- | ---------------------------------------------------------------------- | ------------------------------------------------- |
| IMPRESCINDIBLE    | Elemento mínimo para cumplir los objetivos del MVP.                    | Debe implementarse antes que cualquier otro.      |
| IDEAL             | Agrega un valor significativo al proyecto, pero no bloquea la entrega. | Implementar una vez completado lo imprescindible. |
| OPCIONAL          | Mejora la experiencia o el producto.                                   | Implementar solo si el tiempo lo permite.         |
| OMITIBLE          | No afecta los objetivos ni la evaluación del proyecto.                 | Puede eliminarse sin consecuencias importantes.   |
| FUTURAS_VERSIONES | Funcionalidades fuera del alcance del MVP.                             | No implementar en la versión actual.              |




# Estado


| Estado        | Significado                                    |
| ------------- | ---------------------------------------------- |
| PENDIENTE     | Aún no se ha trabajado.                        |
| EN_DISCUSION  | Se está definiendo.                            |
| DEFINIDO      | Existe una decisión tomada.                    |
| EN_DESARROLLO | Se está implementando.                         |
| IMPLEMENTADO  | Ya existe una implementación funcional.        |
| VALIDADO      | Revisado y aceptado.                           |
| OBSOLETO      | Ya no aplica, pero se conserva como historial. |
